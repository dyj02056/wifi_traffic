# frontend — Next.js 앱 (공공와이파이 안전 지도)

> ※ 이 점수는 실제 해킹 확률이 아니라 위험요인 지표입니다.

설계: [plan.md §9](../plan.md), 인계 문서: [docs/handoff_B.md](../docs/handoff_B.md), 데이터 계약: [contracts/](../contracts/README.md) (1.1.0)

```bash
npm install
cp .env.local.example .env.local   # API 주소, 카카오맵 키, (선택) 구글·네이버 클라이언트 ID
npm run gen:types                  # contracts/schemas → src/lib/types.ts (스키마 바뀌면)
npm test                           # contracts/golden_scores.json 51건
npm run dev                        # http://localhost:3000
```

- 데이터: `NEXT_PUBLIC_API_BASE`(우리 API) 우선 → 응답이 없으면 `public/data`(정적 번들, `bash ../scripts/sync_bundle.sh`)로 자동 전환하고 "정적 백업 데이터" 배지를 띄운다. 한 번 실패하면 5분간은 바로 정적 번들을 쓰고, 5분이 지나면 새로고침 없이 API로 돌아간다. 불러오기 실패 안내의 "다시 시도" 버튼으로 바로 돌아갈 수도 있다(`lib/api.ts retryApi`).
- 지도: 카카오맵(`NEXT_PUBLIC_KAKAO_JS_KEY`, 카카오 개발자 콘솔 [플랫폼 > Web]에 접속 주소 등록). 키가 없으면 지도 자리에 안내만 나오고 나머지는 동작한다.
- 로그인: 구글·네이버 토큰을 API가 검증하고 Neon 회원으로 저장. 로컬 주소에서만 "개발용 로그인"이 보인다(API·DB가 없으면 이 브라우저에만 저장).

| 경로 | 화면 |
|---|---|
| `/` | 인트로·로그인, 처음 로그인하면 사는 지역 선택 |
| `/map` | 지역 선택(첫 지역: `?region` → 회원 지역 → 기본 지역), 장소·주소 검색, 가중치 슬라이더, 등급 필터, 변경 레이어, 화면 안 추천 TOP 3(같은 이름 1개), 순위표(오름·내림차순, 접기), 지점 상세(등급색 머리·신호등), 지역별 "임시(무효)"/"SSID 정보 없음" 표시 |
| `/rules` | 채점 기준표: KaTeX 수식, 100점 구성 막대, 위험요인 카드, 실제 지점 예시 계산 |
| `/sensitivity` | 민감도 분석: 토네이도 차트, 기준·배율 선택, 등급 흐름도(생키), 상위 20곳 표. `lib/score.ts`로 브라우저에서 계산(백엔드 `sensitivity/*.json`은 화면에서 쓰지 않음) |
| `/context` `/about` | 배경 통계·사례 카드(막대는 볼 때마다 0부터 자람, `lib/usePlayOnView.ts`), 데이터와 알려진 한계 |

지도 표시
- 마커: 흰 테두리+진한 바깥선, 안에 기호(낮음 ✓·주의 !·높음 ×), 높음은 크게. 처음 나타날 때·등급이 바뀔 때 움직임, 선택 마커는 파란 고리+맥박(움직임 줄이기 설정이면 멈춤). 거리 기반 묶어 보이기(클러스터링)는 하지 않는다(#43)
- 같은 좌표의 AP 여러 대(예: 보안·개방형 SSID)는 마커 1개로 그린다: 보이는 AP 중 점수가 가장 낮은 것(그 자리 AP를 선택했으면 선택한 것)을 표시하고, 지점 상세에 같은 장소의 다른 AP 목록(점수 낮은 순)과 전환 버튼을 보여 준다. 마커에 올리면 장소 이름과 그 자리 최저 점수(등급색)가 뜬다(`520eef6`, `a8cb50b`)
- 배경 지도는 기본으로 색 30%만 남기고, "지도 색 원래대로/흐리게" 버튼으로 바꾼다(#44)
- "📍 내 위치": 누른 뒤 지도를 한 번 클릭하면 그 자리에 보라색 "내 위치" 핀을 찍는다(Esc로 취소). 브라우저 자동 위치(GPS)는 PC에서 수 km씩 틀려 쓰지 않으며, 지역도 자동으로 바꾸지 않는다. `/api/nearest`는 검색 결과의 지역을 찾을 때만 쓴다

이 버전의 Next.js(16)는 이전과 다른 점이 있다 — 코드를 고치기 전에 `node_modules/next/dist/docs/`를 확인한다(AGENTS.md).
