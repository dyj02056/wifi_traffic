# WiGLE 표본 검증 — R1 "Free만 적힌 SSID" (2026-10-21)

## 질문
공공데이터에 `Public WiFi Free`만 적힌 지점에서 실제로 `Public WiFi Secure`(보안접속)도 함께 송출되는가?
(관련: requests #47, `config/ssid_labels.csv`에서 Free만 적힌 SSID를 `unknown`(0.5)으로 둔 결정)

## 방법
- 원본: `data/raw/snapshots/2026-10-20.csv` (전국 94,166곳)
- 모집단: `ssid_labels.csv`에서 `unknown`이면서 이름에 `free`가 들어간 SSID 지점 20,747곳 + `DJ_Public_WiFi` 656곳
- 표본(계획): Free만 40곳 + DJ 10곳, 무작위(seed 47), 같은 좌표(소수 4자리)·같은 주소는 한 곳만
- 조회: 지점마다 WiGLE `network/search` 1회, 반경 약 50m 상자, `ssidlike=%Public%`
- 판정: Free+Secure 둘 다 잡힘 / Free만 잡힘 / 둘 다 안 잡힘(판단 불가, 계산에서 제외)
- 공유기 고유번호(BSSID) 등 WiGLE 원본은 저장하지 않음. 지점별 개수와 판정만 기록

## 결과

(조회 방식 확인용으로 서울시청 앞 1회 사용: 공공와이파이·보안접속 SSID 모두 정상 수집됨)

- Free가 잡힌 곳: **1곳**, 그중 Secure도 잡힌 곳: **1곳 (100%)**

## 결론
판단 가능한 표본이 1곳으로 기준(10곳)에 크게 못 미친다. 규칙에 따라 **불명(0.5) 유지**,
"WiGLE 검증 시도, 표본 부족"으로 기록한다. 조회된 1곳은 Free와 Secure가 함께 잡혀 현재의 불명 처리와 모순되지 않는다.
