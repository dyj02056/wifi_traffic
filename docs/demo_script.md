# 시연 대본·백업 전환 절차

> 2026-10-21 갱신. 발표 2026-10-21 16:00 KST. 수치는 2026-10-21 수집 기준(배포 주소에서 리허설로 확인).

## 주소

| 용도 | 주소 |
|---|---|
| 화면(메인 시연) | https://wifi-traffic.vercel.app |
| API | https://wifi-traffic-api.vercel.app (`/docs`에 API 목록) |
| 백업 1 — 같은 화면, 데이터만 정적 | 메인 주소 그대로. API가 응답하지 않으면 **자동으로** 정적 데이터로 바뀌고 상단에 "정적 백업 데이터" 배지 |
| 백업 2 — 인터넷 없이 | 발표자 노트북 `web-draft` (아래 사전 점검 2) |

## 사전 점검 (시연 30분 전)
1. **메인 주소 확인**: https://wifi-traffic.vercel.app → 비회원 → 고양시 613곳, 상단에 면책 배너, "정적 백업 데이터" 배지가 **없는지**(API 정상) 확인.
   API를 미리 한 번 깨워 둔다: https://wifi-traffic-api.vercel.app/api/meta 를 열어 글자가 나오면 OK(첫 요청은 1~2초 느릴 수 있음).
2. **백업 2 기동**(발표자 노트북, 저장소 루트에서):
   ```
   cd web-draft
   python -m http.server 5500
   ```
   → http://localhost:5500 → 비회원 → 고양시 613곳 확인. 인터넷이 끊기면 지도 배경만 안 보이고 마커·상세·슬라이더는 동작.
3. **로그인 시연을 한다면**: 발표자 본인 구글·네이버 계정으로 미리 로그인 확인. 네이버·구글 앱이 "개발 중/테스트" 상태면 등록된 계정만 로그인되므로 **다른 사람 계정으로 시연하지 않는다.** 안전하게는 "비회원"으로 진행.
4. 화면 지역 상태 배지 확인: 고양시는 SSID 라벨 확정 지역이라 "임시(무효)" 배지·워터마크가 **없어야** 한다.

## 대본 (약 4분)

1. **첫 화면 → 비회원 입장**
   - "구글·네이버로 로그인하면 사는 지역을 저장해 다음부터 바로 그 지역을 보여 줍니다. 오늘은 비회원으로 보겠습니다."
   - 고양시 지도가 화면에 꽉 차게 열린다. 요약: **높음 109 · 주의 367 · 낮음 137**
   - 꼭 말하기: **"이 점수는 실제 해킹 확률이 아니라 위험요인 지표입니다."**(상단 배너)

2. **가장 점수가 높은 지점 열기** — 순위표 1위 **화전동 행정복지센터 버스정류장 (80.48점, 높음)**
   - R1~R8 막대: 보안접속 미지원(개방형 SSID), 교통시설(정류장), 실외(CCTV 폴), 설치 2020-06 등 근거값이 그대로 보인다.
   - 설명 문단: "비밀번호 없이 연결되는 개방형 와이파이이고, 정류장·역사처럼 많은 사람이 짧게 머물며 오가는 곳입니다." — **근거값 기반 자동 설명**(지어낸 수치 없음).
   - "관리기관 경기도 고양시청 031-8075-2605로 이상 SSID를 신고할 수 있습니다."

3. **가중치 바꾸기 — 보안접속(R1)과 밀집도(R5)만 남기고 나머지 6개 끄기**
   - 지도 색이 0.4초 동안 바뀌고 순위표가 다시 정렬된다.
   - 등급: **낮음 382 · 높음 229 · 주의 2** (365곳 등급 변경), 순위표 위 **"기본 기준 상위 20과 겹침 3개"**
   - "어떤 기준을 중요하게 보느냐에 따라 결과가 크게 달라집니다. 그래서 기준과 가중치를 숨기지 않고 사용자가 직접 바꿔 보게 했습니다."
   - 다시 모두 켜서 원래대로(겹침 20개).
   - (선택) 1개만 남기면 "2개 이상 선택" 안내가 뜨는 것도 보여 줄 수 있다.

4. **장소 검색** — 검색창에 "행신" 입력 → 결과 목록(우리 데이터 + 카카오 주소)에서 하나를 골라 그 위치로 이동.

5. **"내 위치" 버튼**(선택) — 누를 때만 위치 권한을 묻고, 가장 가까운 지점의 지역으로 이동. 위치는 저장하지 않는다.

6. **변경 레이어** — "최근 추가·삭제 지점" 체크
   - "공공데이터를 매일 새벽 자동 수집해 Neon DB에 쌓고, 지난 수집과 비교해 새로 생기거나 없어진 와이파이를 보여 줍니다. 지금은 **2회 수집(2026-10-20~10-21)**이라 고양시 변경은 0건입니다."

7. **배경 통계·사례 탭** — 해킹 발생 추이(경찰청)·민간 침해사고 신고(KISA) 차트, 같은 원리 사례 4건.
   - 꼭 말하기: "이 통계와 사례는 **점수에 반영하지 않습니다.** 국내 공공와이파이 사건도 아닙니다."

8. **마무리** — 지점 상세의 "안전하게 쓰는 법": 개인 핫스팟, 보안접속 SSID 우선, 접속 화면에서 앱 설치 요구 시 즉시 끊기.

## 백업 전환
- **API 장애**(데이터가 안 뜸, 오래 걸림): 화면이 스스로 정적 데이터로 바뀌고 "정적 백업 데이터" 배지가 뜬다. 고양·서초·구로 3곳은 그대로 시연 가능. 그대로 대본 진행.
- **배포 화면 자체 장애**(빈 화면·접속 안 됨 10초 이상): 브라우저 탭을 http://localhost:5500 (백업 2)으로 바꿔 같은 대본 진행.
- **인터넷 끊김**: 백업 2에서 지도 배경 없이 마커·상세·슬라이더로 진행.
- 2026-10-21 리허설 확인: 로컬에서 API를 실제로 끄면 배지 표시·고양시 613곳·지점 상세 정상, 배포 주소에서 백업 모드 강제 시 API 요청 0건으로 정상, web-draft 비회원 → 고양시 정상.
