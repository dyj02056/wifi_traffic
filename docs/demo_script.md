# 시연 대본·백업 전환 절차

## 사전 점검 (시연 30분 전)
1. Next.js 배포 URL 접속 → 면책 배너·구로구 기본 지역 확인 (담당 B)
2. 정적 초안 백업 기동 (담당 A 노트북):
   ```
   cd web-draft
   python -m http.server 5500
   ```
   → http://localhost:5500 에서 지도·클릭·슬라이더 동작 확인. 상단에 '샘플 데이터' 배지가 **없어야** 한다(실데이터).
3. `meta.r1_confirmed=true`(워터마크 없음) 확인. 워터마크가 보이면 final 번들이 아님 → 시연 중단 사유.

## 대본 (plan.md §16-6)
1. "구로구를 선택합니다" → 지도 이동, 등급 색 마커
2. "가장 점수가 높은 지점을 눌러 보겠습니다" → 상세: 총점·R1~R8·근거값·설명·관리기관 연락처
   - 꼭 말하기: "이 점수는 실제 해킹 확률이 아니라 위험요인 지표입니다"
3. "보안접속과 밀집도만 남기고 나머지를 끕니다" → 색 전환, 순위표 재정렬, 기본 상위 20과 겹침 수
4. "최근 추가·삭제 지점 레이어를 켭니다" → "N회 수집, 기간 X~Y"
5. 상세 패널 '안전하게 쓰는 법' 체크리스트로 마무리

## 백업 전환 (Next.js 장애 시)
- 증상: 배포 URL 무응답·빈 화면·지도 미표시 10초 이상
- 즉시 브라우저 탭을 `http://localhost:5500` 정적 초안으로 전환하고 같은 대본 진행
- 인터넷이 끊겨도 지도 타일만 안 보이고 마커·상세·슬라이더는 동작한다
